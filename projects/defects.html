Defects Inspection Platform

A platform for reporting and fixing housing defects. I built the real-time layer and notifications, and found a bug that leaked one household's updates to their whole block.

RoleReal-time & notifications
TypeTeam project
Year2026
StackNode.js, Socket.IO, Supabase

The problem

Residents report defects in their homes, managers assign them, and contractors fix them. Everyone needs to see updates as they happen, but only the updates that belong to them.

What I built

  • The real-time layer. A Socket.IO server that shares the app's Supabase login. When a user connects, they're placed into rooms based on their role, and before anyone joins a room for a specific record, the server checks the database that they're allowed to see it.
  • Notifications that don't disappear. Before, system notifications vanished for anyone offline. I rebuilt them so they're saved like manager announcements, with one resolver that maps each group of recipients to both database rows and live socket rooms. I wired in about 20 lifecycle events and shipped the migration without needing to backfill old data.
  • The contractor portal. An assigned job queue with acknowledge, rectify, hold and resume steps, plus photo and e-signature uploads.

The tricky part: a privacy bug

I found that one household's defect updates were being broadcast to every resident in their block, and fixed it so updates only reach the people they belong to.

I also found an unhandled promise rejection in a socket handler that would have crashed the server for every connected user. I hardened the handlers so one bad event can't take everyone down.
