nomnomz

Send a photo of your meal, get a nutrition log back. A Python bot on a vision model, running 24/7 on a cloud server.

RoleSolo
Size~900 lines of Python
Runs onCloud VM, 24/7
StackPython, Claude API, SQLite

The problem

Logging food is tedious, so most people stop doing it. The idea: make it as easy as taking a photo.

What I built

A Telegram bot: send it a photo of a meal, a nutrition label, or a quick text description, and it logs the nutrition for you. It runs 24/7 on a free-tier cloud server, run as a systemd service.

The tricky part: making AI output reliable

Vision models are good at estimating food, but free-text answers are hard for code to trust.

I used schema-constrained tool calling, so the model has to return a typed object (macros, serving size and a confidence score) rather than free text. One schema covers plated dishes, printed nutrition labels and typed entries.

Estimates can still be wrong, so every one starts as a draft. The user confirms, corrects or cancels it before anything is saved.

Details I got right

  • Database migrations are idempotent, so they're safe to run again on every start.
  • Times are stored in UTC and converted to local day boundaries, so a late-night snack lands on the right day.
